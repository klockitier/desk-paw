Desk Paw

A tiny desktop cat that watches you code, kneads when you type, and cheers when your agents finish.

Install on Mac Get the DMG

Download

One command

Pastes into Terminal, installs the right Mac build, clears Gatekeeper, and launches Desk Paw: 

curl -fsSL https://raw.githubusercontent.com/klockitier/desk-paw/main/install.sh -o /tmp/install-desk-paw.sh && bash /tmp/install-desk-paw.sh

Prefer a file? Download the DMG instead — the script above is just the painless path around Apple’s unsigned-app warning.

Presence

It notices the session you’re in

Idle breath. Cursor watch. Typing paws. Happy hops when something lands. Desk Paw turns long agent loops into a little living corner of your desktop — no accounts, no cloud, no telemetry.

Agent hooks

Steer it from your tools

Point Claude Code, Codex, or Cursor hooks at pawctl. One local loopback poke and the cat shifts into working, waiting, done, or error — right on your desktop.

Privacy

Only activity, never content

  • No analytics, telemetry, or external network calls
  • Keyboard events are noticed, never read or stored
  • pawctl listens on localhost only
